# 兼容性检查

兼容性由 `scripts/check_compatibility.py` 执行，最终配置必须使用 `--strict --require-complete`。不要手动替代脚本判断。

`power_w` 用于电源余量检查，按可见峰值、PPT/MTP 或保守负载估算维护，不等同于厂商页面的默认 TDP；不要据此向用户宣称官方 TDP。

脚本把“是否存在硬不兼容”和“证据字段是否完整”分开报告。读取结构化结果中的 `compatible`、`complete` 和各检查项的 `review_required`：`compatible=false` 表示存在硬不兼容；`compatible=true` 且 `complete=false` 表示仍有下单前复核项；两者都满足时才是完整通过。

无独显整机必须使用已确认带核显的 CPU 和已有 `display_outputs` 证据的主板；严格检查不传 `--gpu`，F/KF、AMD F 或核显状态未知型号会被拒绝。主板视频输出字段缺失时结果为待复核，`--require-complete` 不会放行；字段已核实时报告列出接口类型。显卡限长和显卡供电检查会作为非阻塞跳过项保留。若用户给出显示器输入要求，还要按 HDMI/DisplayPort/VGA 精确过滤，不能把“CPU 已确认带核显”扩写为任意显示器都能直连。

脚本覆盖 CPU/主板 socket、内存代际/数量/容量、显卡限长、M.2/SATA 数量、电源功率、显卡供电、散热扣具与结构能力、散热限高/冷排位、机箱主板版型和电源规格；若机箱或电源有 `psu_length_mm` / `psu_max_length_mm` / `psu_clearance_mm` / `length_mm` 字段，还会复核电源限长。`psu_length_recommended_mm` 是保守建议值，超过建议但未超过物理上限时只能写成“尺寸上可能可装，需按冷排、显卡、硬盘笼和线材复核”；`psu_length_condition` 必须原样保留为复核条件。电源本体长度不包含模组插头和线材弯折空间。部分 ITX、卧式、小型机箱会另有电源限高、转接支架和硬盘笼空间限制；库内没有结构化字段时必须列为下单前人工复核项，不写成完整通过。

同一品牌和完整型号若在目录中出现互相冲突的显卡长度、功耗、显存或供电事实，运行时会返回 `spec_conflicts`。默认推荐隐藏该身份；显式型号/ID 查询仍可用于定位已有配件，但冲突字段不能参与限长、功耗或线材的确定结论，严格检查保持待复核。只有用户按精确 SKU 提供明确规格的同型号 overlay 副本，才清除对应字段的冲突标记；报价补丁和别名不能清除规格冲突。

CPU 与散热扣具只在散热器已有结构化 `socket_support` 时做精确检查：列表明确不含 CPU socket 为硬不兼容，存在交集才报告通过。自定义散热器必须直接提供或从同 SKU 继承 `socket_support`；缺失时进入待复核并被 `--require-complete` 阻塞。现有内置旧库尚未统一维护该字段，缺失时暂记为 `review_required=false` 的非阻塞 `skipped`，以保持既有配置门禁；输出必须说明这一项未执行，不得宣称内置散热扣具已经核实。

“散热能力”是独立的选型完整度门禁，不与扣具或机箱空间混为一谈。它结合 CPU 的保守负载字段、已核实的 Intel K/KF/KS 功耗下限和散热器结构证据检查：65W 及以下可用低功耗级散热；普通非解锁型号在保守字段不超过 150W 时至少单塔四热管或同级；125W–150W 的 K/KF/KS 至少双塔六热管或 240/280 水冷；保守字段超过 150W 至少 360 水冷。这样不会把普通非 K CPU 的短时睿频上限直接等同于持续超频负载。明确低于门槛返回 `warn`，塔体、热管或冷排尺寸未知返回 `msg`；两者都保持 `compatible=true`，但阻塞 `complete` 和 `--require-complete`。这不是温度或降频预测，也不能扩写为厂商官方 TDP 结论。

机箱风扇位属于预算和风道复核项，不是硬兼容项，也不作为 `--strict` 阻塞条件。海景房或好看需求使用水冷时，优先读取机箱 `fan_mounts` / `fan_slots_count`：360 水冷占 3 个 120 风扇位，240/280 水冷占 2 个，420 水冷占 3 个 140 风扇位，480 水冷占 4 个 120 风扇位；剩余风扇位按预算预留。用户明确要求水冷夹汉堡/双面风扇时，冷排自带风扇不抵扣加装风扇预算，但必须提示冷排厚度和空间复核。字段缺失时提示用户自行核实机箱风扇信息，并建议预留加装风扇预算。

只把 `review_required=true` 的检查项列为下单前复核项；非阻塞的 `skipped` 不应误报成硬风险。但只要结果中存在 `skipped`，就不能写“所有检查均已执行”“0 项未核验”或“没有任何待确认信息”；用一句自然语言说明未执行的非阻塞检查即可。`memory_freq_max` 只记录主板官网标称的最高超频频率，不等于任意 CPU、四槽布局和任意套条都能稳定达到。6000 C28、7200/8000 等精确需求仍要按主板版本、CPU 内存控制器、DIMM 数量、官网 QVL 和 BIOS 版本复核，不阻塞 DDR 代际、插槽数和容量已经通过的普通整机。显卡限长、散热空间、电源形态等硬兼容字段缺失仍会阻塞。

SSD 的 `dram_cache=true` 只在官方资料明确板载 DRAM 时写入；`dram_cache=false` 可表示官方明确 DRAM-less/HMB。SLC Cache、nCache 或仅有高顺序读写参数不能当作独立 DRAM 证据。剪辑、直播录制、AE 缓存、摄影和频繁读写场景若字段缺失，必须在线核对具体容量和版本，不能凭系列印象承诺带缓存。

电源功率检查只覆盖硬下限；选型余量按已加载的通用选件策略和最终用途说明取舍，不回读其他 reference。

普通 ATX/MATX 机箱默认选择 ATX 电源。SFX/SFX-L/FLEX/TFX 小电源用于 ITX、小型、NAS、卧式或用户明确复用小电源的场景；装入普通 ATX 机箱即使可用转接支架，也默认按不通过处理，不写成推荐配置。

背插/BTF/Project Zero 不由脚本自动推断。用户明确要求背插时，必须人工确认背插主板与背插兼容机箱，普通机箱不能按背插兼容处理。

主板 M.2 / SATA 数量缺失属于普通装机非阻塞项；单 SSD 整机可列为下单前复核点。用户明确多硬盘、旧 SATA 盘复用、剪辑素材盘、NAS/存储或工作站扩展时，必须补查后再判断。

SATA 接口不等于 M.2 形态。`2.5 SATA` / `3.5 SATA` 占用主板 SATA 口，只有明确标为 M.2 SATA 的硬盘才占用 M.2 插槽并检查该插槽的 SATA 模式。SATA 硬盘缺少形态证据时进入待复核，不得默认写成 M.2 2280。

脚本只检查 M.2/SATA 数量，不自动判断 PCIe 通道共享。多 M.2、PCIe 5.0 SSD、USB4/雷电、采集卡、万兆网卡、声卡或扩展卡场景，必须人工查主板说明书/规格页的 lane sharing：有些插槽会让显卡降到 x8、让 M.2 降到 x2/x4，或禁用 SATA/PCIe 插槽。普通单 SSD 游戏机只列为非阻塞提示，不为此默认升级主板。

显卡的物理 x16 插槽长度和电气 x8 不等于同一概念。RTX5060/RTX5060Ti 等中端卡若官方/规格页为 PCIe x8，在 PCIe 4.0/5.0 平台上不默认视为搭配错误；老 PCIe 3.0 平台、旧主板升级或用户明确追求满血带宽时，再列为复核项。
